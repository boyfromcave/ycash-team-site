lightwalletd

The server that light wallets such as YEW talk to. It reads the chain from a Ycash node and sends each wallet only what it needs.

For people who run servers: it is built from the source on GitHub and runs beside your own Ycash node. A public server for the fast testnet answers at fastnet-lightwallet.ycash.team, port 443.
